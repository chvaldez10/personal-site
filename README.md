# Personal site

Christian Valdez’s personal site. The app lives in [`chvaldez10/`](chvaldez10/).

Start with the [app guide](chvaldez10/README.md) for local setup, a visual map of the Next.js and Convex architecture, and examples of forms, retrieval, validation, authentication, and media uploads.

Use Node 24 and the pnpm version in `chvaldez10/package.json`. From the app folder, run `corepack enable`, `pnpm install --frozen-lockfile`, then `pnpm dev`. The frontend uses the configured shared Convex deployment.
