# Reusable progress checklist

Use with [README.md](./README.md). Copy this checklist when working in another repo.

Tick a box when the step is finished. Mark migration-only steps “not needed” for a new setup.

- [ ] Step 1 — You open the app folder.
- [ ] Step 2 — You install Convex if needed, create the test project, and tell me setup is done.
- [ ] Step 3 — Migration only: we save the old data/files and note existing users.
- [ ] Step 4 — I connect the app to Convex; you check the working result.
- [ ] Step 5 — If needed: we set up or keep login and check private access.
- [ ] Step 6 — You check the full app on your computer; I fix failures.
- [ ] Step 7 — I prepare the online test copy; you enter settings and check it.
- [ ] Step 8 — I prepare launch; you approve publishing and check the public app.
- [ ] Step 9 — Migration only: you decide when cleanup and stopping the old service are allowed.
